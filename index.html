SkyPulse — Airline Customer Satisfaction Prediction

A production-ready Machine Learning web application and data pipeline built with Python, Scikit-Learn, and Streamlit. SkyPulse automatically ingests airline customer sentiment and flight performance data, builds an end-to-end preprocessing and ensemble learning pipeline using Random Forest, and provides an interactive web interface for real-time predictions and model exploration.

Key Engineering Highlights
  • No Data Leakage: Preprocessing transformers fit strictly on the training partition and transformed on test sets.
  • Robust Missing Value Handling: Automated median imputation handles edge cases in arrival delays seamlessly.
  • High Generalizability: Evaluated on 25,976 unseen holdout passengers with balanced precision (95.48%) and recall (95.43%).
  • One-Click Launcher: Includes run_app.bat for instant Windows execution without manual setup.
